# data/

Storage for datasets and manifests (Phase 2/3, currently placeholders).

- `manifests/` — JSONL manifests per PRD §6.1 / §8. Empty until Phase 3.
- Audio files recorded by the app live in `outputs/` (git-ignored), NOT here.

Nothing in this directory should ever be committed with unclear licensing
(see `docs/dataset_policy.md` and PRD §8). Do not add private audio here.
