## Results

**Engine smoke test (`app/tts_engine.py`):**
- status `success`, record saved to `outputs/run_log.jsonl`
- input 81 chars → output 4.8 s of speech @ 48 kHz (was initially mislabeled 16 kHz — see finding below)
- gen 9.26 s → **corrected RTF ≈ 1.9** (0.64 was an artifact of the mislabeled sample rate)

**Finding (sample rate):** checkpoint `config.json` declares
`audio_vae_config.out_sample_rate = 48000` while `sample_rate: 16000` is the internal latent rate.
All WAVs written before verification were labeled 16000 → 3× slow playback. Config + engine now
write 48000 (verified both from config.json and by listening).

**Expressive control probe (Phase 4 feasibility — NOT an implemented feature, PRD §5.2):**
VoxCPM2's CLI-style control syntax `({style}){text}` was probed on 6 styles
(neutral/excited/sad/whispers/angry/laughs) at fixed settings (cfg 2.0, timesteps 10).
User listening verdict: **all 6 judged effective**, natural pacing at 48 kHz.
Saved to `outputs/expression_test/` (evidence retained outside Git per §14; not a UI feature).
